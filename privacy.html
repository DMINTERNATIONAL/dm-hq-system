DM 캘린더 개인정보 처리방침

DM INTERNATIONAL 사내 업무 앱 · 구글 캘린더 연동 기능 · 시행일 2026년 10월 30일

DM INTERNATIONAL(이하 '회사')은 직원용 사내 업무 앱(DM 앱)의 캘린더를 구글 캘린더와 맞춰 주는 기능을 제공합니다. 이 기능은 회사 직원만 쓸 수 있고, 원하는 사람만 직접 연결합니다. 이 문서는 그 과정에서 구글 계정 정보를 어떻게 쓰는지 설명합니다.

1. 받는 정보

정보쓰는 곳
구글 계정 이메일 주소누구의 계정인지 표시하고, 회사 공용 캘린더를 그 계정에 공유하는 데 씁니다.
구글 캘린더 접근 권한(연결 키)DM 캘린더 일정을 구글 캘린더에 쓰고, 구글에서 고친 일정을 DM 으로 가져오는 데 씁니다.
DM 이 만든 캘린더 안의 일정제목 · 날짜 · 시간 · 장소 · 메모 · 반복 설정을 양쪽에 맞춥니다.

회사는 연동 기능이 직접 만든 캘린더('DM 내 일정', 'DM 전체 회사' 등)만 읽고 씁니다. 사용자가 원래 갖고 있던 다른 캘린더의 일정, 연락처, 메일, 드라이브 등 다른 구글 데이터는 읽지 않습니다.

2. 쓰는 목적

  • DM 앱의 업무 일정을 직원 본인의 구글 캘린더(휴대폰 캘린더 앱 포함)에서도 볼 수 있게 하기
  • 구글 캘린더에서 만들거나 고친 일정을 DM 앱에 반영하기

받은 정보는 위 목적 외에 쓰지 않으며, 광고 · 판매 · 분석 목적으로 쓰거나 다른 곳에 넘기지 않습니다.

3. 보관과 보호

  • 연결 키는 회사 서버만 읽을 수 있는 잠긴 저장소에 보관합니다. 다른 직원이나 앱 화면에서는 볼 수 없습니다.
  • 연결 상태(어느 이메일로 연결됐는지)는 본인 확인과 운영을 위해 회사 앱 안에서만 보입니다.
  • 모든 통신은 암호화(HTTPS)되어 오갑니다.

4. 보관 기간과 삭제

  • DM 앱 캘린더의 구글 캘린더 연결 → 연결 끊기를 누르면 연결 키를 바로 지우고 구글에 권한 취소를 요청하며, 연동 기능이 만든 'DM 내 일정' 캘린더를 지웁니다.
  • 구글 계정 설정(myaccount.google.com/permissions)에서 직접 권한을 취소할 수도 있습니다. 이 경우 회사는 더 이상 구글 캘린더에 접근하지 못합니다.
  • 퇴사하면 연동을 멈추고 회사 공용 캘린더 공유를 뺍니다.
  • DM 앱 안의 일정은 회사 업무 기록으로, 사내 규정에 따라 보관합니다.

5. 구글 사용자 데이터 정책 준수

DM 앱이 구글 API 로 받은 정보를 쓰고 다른 앱으로 옮기는 방식은 '제한적 사용(Limited Use)' 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.
